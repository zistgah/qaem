# qaem — Geometry of Persisting (Beyond Life)

**Volume III of the Geometry Trilogy**, by **Abhishek Choudhary** (AyeAI). Twenty-three posters, one per chapter, published as a static book on the [kitab](https://github.com/zistgah/kitab) template.

> Volume I asked how a semantic structure can exist at all. Volume II asked how it stays alive. Volume III asks what survives when every physical realization is allowed to change — across substrates, across the total loss of context, and across deep time.

## Read

Five parts, twenty-three chapters, twenty-four posters including the cover.
